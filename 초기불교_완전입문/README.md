# 초기불교 완전입문

초기 니까야(Nikāya)·아함(Āgama) 전승을 중심으로, 부처님의 가르침을 처음 접하는 독자가 **괴로움의 문제 → 조건 → 갈애와 취착 → 오온과 무아 → 수행 → 열반 → 전체 통합**의 흐름으로 읽을 수 있도록 구성한 13강 입문 해설입니다.

각 강의 본문은 완성된 통합정제본을 그대로 게시했습니다.

## 전체 흐름

`부처님이 무엇을 문제로 삼았는가 → 검토 방법 → 윤리와 업 → 사성제와 중도 → 연기 → 오온과 무아 → 점진적 훈련 → 호흡과 마음챙김 → 자애 → 재가생활 → 열반 → 집착 없는 인식 → 전체 통합`

## 읽을 때의 주의

- 초기불교 원문과 후대의 해석을 가능한 한 구분합니다.
- 무아를 단순히 “나는 존재하지 않는다”로, 괴로움을 “인생은 전부 고통이다”로, 연기를 “모든 것이 서로 연결되어 있다”로 축소하지 않습니다.
- 각 강의 마지막에 있는 **호킨스 박사님 언어로 다시 보기**는 초기 경전의 직접 표현이 아니라 비교 해설입니다.
